# Xkeen-UI v3.1.1-beta.2

Изменения относительно v3.1.1-beta.1:

- После восстановления из резервной копии установщик восстанавливает библиотеки веб-терминала и недостающий файл доверенных сертификатов рабочего pip. Проверка TLS остаётся включённой.
- Если удалённая или приостановленная подписка использовалась для DNS-over-VLESS, панель пересчитывает маршрут и обновляет индикаторы. «Перепроверить» может восстановить настройки при распознанных устаревших ссылках.
- Копия для отката панели сохраняется после операций с модулями и смены профиля.
- DevTools показывает, что команда перезапуска принята, и подтверждает готовность после запуска нового процесса панели.
- При выборе стабильного канала можно вернуться с беты на актуальную стабильную версию, даже если её номер ниже. Запоздалая проверка прежнего канала больше не возвращает предложение беты.
