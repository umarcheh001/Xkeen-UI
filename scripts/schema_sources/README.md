# Схемы Xray

`xray-schemas.json` — исходник четырёх схем редактора. Общие определения лежат
в `definitions`. В `schemas` находятся корневые формы отдельных редакторов,
списки используемых определений и различия в `overrides`.

Общие поля меняйте в `definitions`; отличия конкретного редактора — в его
`overrides`. В override `set` заменяет или добавляет поля, `remove` удаляет
поля, `edit` рекурсивно изменяет вложенный объект. После правок выполните
`npm run schemas:xray:refresh` и добавьте в коммит исходник и изменившиеся
готовые схемы. `npm run schemas:xray:check` проверяет их соответствие.

Готовые файлы сохраняют внутренние `$ref` и загружаются редакторами напрямую;
на роутере генератор и исходник не нужны. Проверка описей перед коммитом также
сверяет готовые схемы с исходником из индекса.
