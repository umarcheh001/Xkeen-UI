# Сверка команд XKeen

Каталог панели: `xkeen-ui/services/xkeen_commands_catalog.py`. Он же задаёт разрешённые флаги API. Автоматическое добавление флагов из справки не допускается: сначала нужно проверить назначение, аргументы, интерактивность, совместимость с терминалом и версии XKeen.

## Повторная сверка

1. Записать версию (`xkeen -v`), канал, источник сборки и дату. Получить вывод `xkeen -h` на нужной установке; заранее проверить поведение соответствующей версии, включая её запуск и импорт скриптов. Не запускать остальные команды ради инвентаризации.
2. Сохранить вывод как файл UTF-8, отдельно для каждой версии и канала. Удалить персональные данные, если они есть. Убедиться, что вывод полный: частичная справка даст ложные расхождения.
3. В корне репозитория выполнить `python scripts/check_xkeen_commands.py путь/к/справке.txt`. Скрипт читает файлы локально, не запускает XKeen, не обращается к сети и ничего не изменяет. Цветовые ANSI-последовательности игнорируются.
4. Сверить каждый пункт отчёта со справкой и обработчиком флага в исходниках конкретной версии. Наличие в справке не гарантирует успешную работу и не определяет доступность в других версиях. Отдельно проверить описания и побочные действия: сравнение выявляет только названия флагов. Внутренние и недокументированные ключи требуют отдельного анализа.
5. Для проверенных изменений обновить каталог и тесты; сохранить в отчёте версии, ссылки на ревизии и причины решений. Команды, отсутствующие в новой версии, не удалять без проверки поддерживаемых старых версий. Затем повторить сверку.

Скрипт распознаёт флаги в начале строки после пробелов; аргументы после флага не сравниваются. Неузнанная или пустая справка считается ошибкой. Код 0 означает, что отчёт создан, а не что различий нет. Формат справки может измениться — сравнивайте количество распознанных флагов с оригиналом.

## Проверка 11.11.2026

Официальный `jameszeroX/XKeen`, main, ревизия `a3154f5ffc8d033792126ddd8561d9228807645b`: текст получен вызовом функции `help_xkeen` из `scripts/_xkeen/about.sh` в локальной копии, а не с роутера. В справке 65 разных флагов, в исходном каталоге панели 62.

- Только в справке: `-cfd`, `-di`, `-dscp`, `-health`, `-killswitch`, `-mtest`, `-pbr`, `-sb`, `-startvb`, `-uy`, `-xtest`.
- Только в панели: `-delmodules`, `-drk`, `-drm`, `-drx`, `-modules`, `-rrk`, `-rrm`, `-rrx`.

Это расхождения на момент проверки, а не перечень автоматически одобренных изменений. В исходниках обработчик `-uy` устанавливает или обновляет yq. Например, для `-dm` актуальная справка указывает удаление Mihomo вместе с yq, а для `-d` отличается описание от каталога панели; такие отличия следует проверять отдельно от флагов.

После добавления `-uy` в каталог остаются 10 флагов только в справке и те же 8 только в панели. Доступность `-uy` в старых версиях здесь не установлена; панель пока не фильтрует команды по установленной версии.
