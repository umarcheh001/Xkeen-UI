# Аналитика трафика Mihomo

Состояние на 23 сентября 2026 года.

Раздел `Clash API → Диагностика → Аналитика трафика` хранит локальную
агрегированную статистику за последние семь дней.

В интерфейсе доступны фильтры по устройству, VPN/узлу и ресурсу, раздельные
download/upload, а также экспорт текущего среза в CSV и JSON.

## Что учитывается

- устройство: IP и имя из списка клиентов Keenetic;
- маршрут и конечный узел из фактической `chains` активного соединения Mihomo;
- запрошенный ресурс: `sniffHost`, `host` или destination IP;
- download/upload по дельте счётчиков соединений;
- общий трафик клиента по счётчикам Keenetic;
- оценка трафика вне Mihomo:
  `общий трафик Keenetic − наблюдавшийся трафик Mihomo`.

## Ограничения точности

Mihomo не предоставляет готовую долговременную статистику по устройствам.
Коллектор снимает `/connections` раз в 10 секунд, поэтому очень короткие
соединения между снимками могут не попасть в распределение по VPN и доменам.
Показатель Mihomo является наблюдаемой нижней границей.

Остаток «Вне Mihomo» является оценкой и может включать локальный LAN-трафик,
служебные запросы роутера и расхождение периодов двух источников. Интерфейс
явно маркирует его как оценочный.

## Хранение и приватность

- SQLite: `<UI_STATE_DIR>/mihomo-traffic.sqlite3`;
- права файла: `0600`;
- агрегация по пятиминутным интервалам;
- хранение до семи дней;
- количество маршрутов и ресурсов в интервале ограничено;
- payload пакетов, URL-пути, секрет Mihomo и содержимое запросов не хранятся.

Карточка «Качество данных» показывает состояние обоих источников, число ошибок,
усечённые снимки `/connections`, размер локальной базы и процент наблюдаемого
трафика. Это позволяет отличать проблемы сбора от обычного прогрева истории.

## Настройка

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `XKEEN_MIHOMO_TRAFFIC_ANALYTICS_ENABLE` | `1` | `0` полностью отключает сбор |
| `XKEEN_MIHOMO_TRAFFIC_SAMPLE_SECONDS` | `10` | интервал снимка `/connections` |
| `XKEEN_MIHOMO_TRAFFIC_CLIENT_SECONDS` | `30` | интервал счётчиков клиентов Keenetic |
| `XKEEN_MIHOMO_TRAFFIC_RETENTION_DAYS` | `7` | срок хранения, ограничен семью днями |
| `XKEEN_MIHOMO_TRAFFIC_DEMO` | `0` | `1` возвращает синтетическую статистику и не запускает фоновый сбор |

## Офлайн-разработка

Для визуальной проверки панели без роутера:

```bash
XKEEN_MIHOMO_TRAFFIC_DEMO=1 python3 xkeen-ui/run_server.py
```

Для проверки алгоритма и семидневного хранения:

```bash
npm run traffic:simulate
npm run traffic:soak
```
