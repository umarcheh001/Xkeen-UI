# DNS по правилу Xray

В DNS-over-VLESS под общими DNS-серверами находится раздел «DNS для отдельных правил». В нём можно добавить несколько строк. Пользователь выбирает существующее доменное правило и вводит один DNS-сервер для него. Домены и выход показываются из правила. Остальные домены пользуются общим DNS-маршрутом.

В список входят правила основного файла маршрутизации с уникальным `ruleTag`, условием только по имени (`full:` или `domain:`) и одним прокси-`outboundTag`. Для совместной привязки перекрывающихся правил узкое правило может стоять раньше общего. Обрабатываются A и AAAA. Выделенные серверы участвуют только в запросах своих доменов. При тайм-ауте последней подходящей привязки Xray завершает запрос в этой группе. Поддержка проверена на Xray 26.11.9.

Раздел редактируется вместе с остальными DNS-серверами. При безопасном включении панель пишет служебный DNS-фрагмент и правила, проверяет конфигурацию и использует штатный откат. При отключении служебные правила удаляются, выбор сохраняется. Сохранение или восстановление основного routing через панель пересчитывает привязки, сохраняя комментарии. Если связанное правило удалено или перестало подходить, операция сообщает, какая привязка требует решения. Для правок вне панели окно показывает расхождение. Отдельные маршруты стоят в начале основного routing. Их служебные выходы наследуют марку Entware. Запросы к исчезнувшему прокси завершаются на его привязке.
