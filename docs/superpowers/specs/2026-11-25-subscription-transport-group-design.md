# Несколько транспортов для одного выхода

В подтверждении режима «Только подписка» для ручного выхода можно выбрать один или несколько узлов. Например, для `VPS_US` подходят Reality и XHTTP одного VPS. Группа нужна правилам сайтов и их отдельным запросам A и AAAA. Общий DNS использует её, если до перехода был закреплён за тем же ручным выходом.

## Выбор подхода

- Основной транспорт с резервом сохраняет явный приоритет. Для новых транспортов нужно определять порядок.
- Выбор доступного узла из группы подходит для двух и более транспортов и учитывает результаты наблюдения Xray. Владелец предпочёл этот вариант.

## Интерфейс и поведение

- Пользователь выбирает подписку и отмечает конкретные узлы флажками. В первом варианте группа собирается из одной подписки. Один отмеченный узел сохраняет текущий способ привязки. Существующий необязательный пропуск сохраняется.
- Для нескольких отмеченных узлов показываются их число и выбранные названия. Перед применением проверяется актуальность набора. Пользователь выбирает транспорты одного VPS. Совпадение IP проверяется при приёмке. Панель не обращается к внешнему сервису проверки IP при каждом применении подписки.
- Новые соединения идут через доступные узлы из выбранной группы. Наблюдение Xray проверяет транспорт. Выбор узла между отдельными запросами может меняться. В случае отказа всей группы запрос завершается.
- Все резолверы выделенной привязки используют ту же группу, что и трафик сайтов. Список резолверов и его порядок сохраняются. При исчерпании списка запрос завершается.
- Если общий DNS был явно закреплён за заменяемым выходом, полный отказ группы действует как отказ этого прежнего выхода. Поведение штатного сторожа общего DNS сохраняется.

## Конфигурация и совместимость

- Выбор хранится по стабильным идентификаторам подписки и узла. Старый выбор из одного узла остаётся действующим. При обновлении новый тег вычисляется по сохранённому ключу. Если часть узлов исчезла, остаются доступные выбранные узлы, а панель сообщает, какие из группы пропали. Сохранённый узел возвращается в группу при повторном появлении. Если исчезла вся группа, конфликтующее обновление отменяется.
- Группа включает ровно выбранные outbounds. Xray сопоставляет selectors по префиксам, поэтому проверка учитывает все подходящие теги. При конфликте префиксов применяется однозначное представление или сообщается конфликт до записи. Балансировщик покрывается действующим наблюдением. При отказе всех членов используется выход, завершающий запрос.
- Пауза и выход из «Только подписка» восстанавливают ручной выход и DNS-привязку. Возобновление снова применяет сохранённые узлы. Существующая транзакция проверяет конфигурацию и восстанавливает снимок при отказе. Изменения маршрутов, наблюдения и DNS применяются вместе.
- Удаление подписки, от которой зависит группа, требует новой замены, если режим «Только подписка» продолжит действовать. При удалении последней подписки сохраняется штатный возврат ручного выхода.

## Приёмка

Проверить один узел и группу, отказ каждого транспорта и всей группы, совпадение внешнего IP, маршруты HTTPS и DNS, несколько резолверов, смену и исчезновение тегов при обновлении, паузу, возобновление и откат. Браузерный тест проверяет список флажков, сохранённый выбор и недоступные узлы. Для конфигов используется Xray от 26.11.9.
