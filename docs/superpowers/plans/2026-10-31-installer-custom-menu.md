# Интерактивный выбор Custom — план

**Цель:** реализовать согласованный выбор модулей из спецификации `docs/superpowers/specs/2026-10-31-installer-custom-menu-design.md`.

**Подход:** сохранить неинтерактивный интерфейс и обновление, выделить интерактивный выбор в самостоятельный Python-компонент, вызываемый POSIX shell-установщиком; использовать стандартную библиотеку и существующие средства терминала, предусмотрев резервный ввод.

1. Проверить обнаружение ядер, обработку сигналов, имеющиеся pty-тесты и доступные средства тестирования; записать ограничения.
2. Сначала создать падающие тесты пользовательского выбора, зависимостей, возврата и терминальных режимов; реализовать меню и повторить проверки.
3. Сначала тестами закрепить порядок вопросов о дополнениях и совместимость неинтерактивного запуска; перенести вопросы и проверить сценарии.
4. Проверить синтаксис shell, профильные тесты и полный `npm run test:py`; изучить diff, зафиксировать ограничения проверки терминалов, обновить handoff и память.

Ограничения: POSIX/BusyBox, без новых зависимостей; не менять пользовательские данные, не коммитить и не пушить без просьбы; установка на роутер не входит в задачу.
