# Прогресс установки ядра — план

**Цель:** реализовать согласованные макеты загрузки и перезапуска для Xray и Mihomo.

**Спецификация:** `docs/superpowers/specs/2026-11-10-core-install-progress-design.md`.

**Устройство:** `core_installer.py` передаёт в состояние операции счётчики загрузки; `core_source.js` вычисляет скорость между опросами и отображает данные; стили распределяют этапы и добавляют отступ. Существующие тестовые загрузчики сохраняют интерфейс.

## Границы и проверки

- Размер отсутствует или некорректен: показывать полученные байты, не выдумывать общий размер и оставшееся время.
- Первый опрос, остановка передачи, повторная операция: не использовать старую скорость.
- Ошибка загрузки или контрольной суммы: сохранять прежний откат и не раскрывать недостоверный прогресс.
- Пять и семь этапов, узкий экран: этапы остаются читаемыми и не выходят за границы.
- Одновременная установка/перезапуск: сохранить текущую блокировку и существующий безопасный процесс.

## Шаги

1. Добавить падающие тесты потокового загрузчика и API состояния на известный и неизвестный размер, несколько порций и ошибку; реализовать счётчики без изменения контракта внедряемых загрузчиков; выполнить `tests/test_core_installer.py` и тесты API.
2. Добавить падающие браузерные сценарии реального прогресса, сброса скорости, отсутствующего размера и распределения пяти и семи этапов; реализовать расчёт и отображение, согласованные отступы; собрать фронтенд и выполнить затронутые e2e.
3. Проверить `git diff --check`, LF, контракты и конечное состояние; обновить память и handoff. Коммит и установку не выполнять без отдельной команды владельца.
