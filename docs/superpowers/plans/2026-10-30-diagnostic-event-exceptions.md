# Подтверждения и исключения событий диагностики

Цель: подтверждать отдельные проблемы и предупреждения и отключать повторные записи выбранного типа и источника, сохраняя отображение текущего состояния.

1. Изучить жизненный цикл активных событий и сохранения истории; разделить состояние измерений и фильтрацию журнала, не меняя данные существующей истории.
2. Написать падающие тесты для подтверждения и исключений: тип и источник, перезапуск, закрытие и повторное возникновение, отмена исключения, повреждённые данные, отсутствие ключа источника и независимость текущего состояния.
3. Добавить устойчивое хранение подтверждений и исключений на роутере и защищённые API для чтения и изменения. Сохранение исключений не должно зависеть от срока хранения журнала.
4. Добавить интерфейс по согласованным макетам: действия только для проблем и предупреждений, явная область исключения, список и отмена; существующие записи не удалять.
5. Проверить целевые Python и браузерные тесты, сборку фронта, полную Python-проверку и адаптацию окна; отдельно сообщить о существующих падениях и ограничениях идентификации устройства.
