# Чистый старт до NTP — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Корректные даты новой истории и событий после NTP без сохранённой истории.
**Architecture:** Сдвиг начала новой истории и событий на разность wall clock и uptime; перенос кольцевых точек с сохранением значений. Метаданные связывают перенос только с текущей загрузкой Linux.
**Tech Stack:** Python, pytest, существующие HistoryStore/TopStore/ProblemTracker/Collector.
**Spec:** docs/superpowers/specs/2026-10-28-router-cold-clock-design.md

## Global Constraints

- Сохранённая история прежних загрузок не переносится; format version=1 совместим.
- Стартовое ожидание интернета и временный fresh до NTP сохраняются.
- Python LF, фронт не меняется; роутеры только читать, не перезагружать и не очищать.

## Review Focus

- Частичные интервалы avg/max и открытые накопители не теряются при сдвиге и смене индексов кольца.
- Несколько коррекций в обе стороны не оставляют старых дат и не складывают временные эпохи.
- Реальная пауза сборщика не считается NTP; нет uptime — нет догадок.
- Ранний рестарт с сохранением и коррекция между процессами учитывают тот же boot_id без второго boot event.
- Старый формат/другой boot_id не позволяют переносить достоверную историю.
