# Группа транспортов подписки

Цель — выбирать доступный транспорт из явно отмеченных узлов одного VPS для сайтов и DNS отдельного правила.

Спецификация в [проекте группы транспортов](../specs/2026-11-25-subscription-transport-group-design.md).

В рабочей копии уже есть согласованные правки DNS и интерфейса. Реализация работает поверх них. Один агент правит код, проверяющий читает изменения. Архив и установка выполняются отдельно.

## Особые случаи для проверки

- Селектор-префикс захватывает соседний тег. Посторонний узел не должен попасть в группу.
- Если узлов не осталось, прежняя конфигурация остаётся на месте и панель сообщает причину.
- При возврате узла с тем же ключом группа обновляется без ручного выбора.
- Один узел, старые записи выбора и режимы вне «Только подписка» работают как раньше.
- Без живых транспортов маршрут не переходит на основной балансировщик, прямой выход или общий DNS.
