> Выполнять последовательно с падающими тестами. Фиксация git выполняется отдельно по правилам проекта.

**Цель** — несколько привязок DNS к существующим доменным правилам.

**Архитектура** — запрос `rule_dns` содержит пары `rule_tag` и `upstream`. Бэкенд извлекает `domains` и `outbound_tag` из routing, генерирует выделенные DNS-серверы и правила по их тегам и сохраняет применённый снимок. Обычное сохранение routing готовит и проверяет обновлённую пару файлов.

**Спецификация** — [DNS по правилу Xray](../specs/2026-11-23-dns-by-xray-rule.md).
