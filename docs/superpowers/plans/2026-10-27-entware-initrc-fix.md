# Предупреждение о сценарии остановки Entware — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Показывать в диагностике отсутствие opkg initrc, исправлять его после подтверждения и сохранять выбор «Скрыть».

**Architecture:** Отдельный Python-сервис читает running-config через utils/firmware.py и выполняет две отдельные команды изменения и сохранения. Blueprint диагностики предоставляет три API, скрытие хранится через существующий UISettingsStore. Контроллер dashboard.js управляет запросами и временем жизни полосы; view.js рисует её под строкой состояния внутри shadow DOM.

**Tech Stack:** Python, Flask, pytest, JavaScript, Playwright; существующие механизмы авторизации, CSRF и ui_settings.

**Spec:** `docs/superpowers/specs/2026-10-27-entware-initrc-fix-design.md`

- Нет ndmc, ошибка чтения или нет opkg disk при отсутствующем initrc → `unknown`, без полосы.
- Целевой путь: `/opt/etc/init.d/rc.unslung`. Команды `opkg initrc /opt/etc/init.d/rc.unslung` и `system configuration save` — отдельные вызовы run_ndmc.
- Установщик и центр уведомлений не менять. Конфигурацию тестовых роутеров менять только с отдельного согласия владельца.

## Review Focus

1. initrc появился после показа полосы: перед записью перечитать конфигурацию, сохранить существующий чужой путь (задача 1).
2. Настройка применилась, но сохранение не удалось: ответ — ошибка, повторная попытка должна повторить сохранение, а не объявить успех только по running-config (задача 1).
3. Поздний ответ после закрытия/повторного открытия: не менять состояние нового открытия; один GET на открытие, без повторов на тиках (задача 3).
4. Скрытие и изменение тарифа: оба ключа переживают загрузку и частичные обновления; строка `"false"` не становится true (задача 2).
5. Ошибка прошивки с HTML и длинным текстом: показывать как текст, без выполнения разметки и горизонтальной прокрутки (задача 3).
