# Mihomo: подготовка поставки импорта

## Описание изменений для выпуска

Окно добавления узлов показывает результат распознавания и назначение подписки,
позволяет проверить итоговые изменения и выбрать перенос в черновик, сохранение
или сохранение с применением. При ошибке применения сохранённый файл и состояние
задачи показываются отдельно. Массовая вставка подготавливается одним запросом;
список карточек ограничен без обрезания импортируемых данных.

## Проверка перед поставкой

Этапы 0–8 и ограничения проверок описаны в документах этапов 6–8. Исходный
ESM, сгенерированные файлы и описи проверяются штатными командами сборки,
`frontend:verify:static` и `inventory:check`. Пакет и фактический выпуск
готовятся отдельно, по просьбе владельца; сам этот документ выпуском не является.

28 октября на `0ec27491`: две последовательные сборки прошли, SHA-256 всех 121 файла
`frontend-build` совпали. Проверки `frontend:verify:static` и `inventory:check`
прошли. Результаты полного pytest и браузерных тестов приведены в этапе 8.

Старый одиночный API и мост совместимости сохраняются для существующих
потребителей. Текстовый просмотр без редактора и восстановление состояния —
действующие пути, а не временные переключатели старого интерфейса. При проверке
этих механизмов не найдено доказанно неиспользуемых фрагментов для удаления;
в `panel-operator.css` проверены 44 имени классов `xk-mi-*`: все встречаются
в разметке или JS. Проверка имён не доказывает достижимость каждого состояния
и не является аудитом остальных стилей проекта.

## Откат

До установки сохранить резервную копию конфигурации, профилей и файла состояния
`mihomo_subscriptions.json`, определить точную установленную версию и сравнить
её с выбранным архивом. Установка прежнего полного архива затрагивает и другие
изменения панели; архив нельзя выбирать только по возрасту. Не откатывать
отдельный JS-файл или серверный маршрут без совместимой остальной части.

Текущий `xkeen-ui/install.sh` пытается сохранить активный конфиг и профили,
но копирование подавляет ошибки (`|| true`); поведение другого архивного
установщика и сохранность подписок этим не доказаны. Перед реальным откатом
нужно проверить установщик выбранного архива и резервные копии, затем в отдельном
тестовом окружении сверить хеши данных, активный профиль, подписки и работу
панели до и после. Откат на роутере и совместимость всех данных между версиями
не проверены; безопасный автоматический откат не заявляется.

### Изолированная проба 28 октября

В отдельный каталог сначала применён текущий full-профиль; затем применён
`module_profile_install.py` из `911c0aa0` (непосредственно перед выделением
нового импортера). Все три файла с искусственными данными — состояние подписок,
активный конфиг и профиль — сохранились с теми же SHA-256. Оба вызова apply
завершились с кодом 0. Между выбранным коммитом и текущим состоянием находятся
59 коммитов на момент опыта (`0ec27491`), включая не связанные с импортом изменения.

Это проверка только помощника профиля, не полного `install.sh` и не архива
выпуска. Снимок Git не содержит `static/frontend-build`: после наложения старого
профиля manifest отсутствует. Запуск панели и откат полного готового архива не
проверены; такой снимок нельзя считать рабочим пакетом отката. Скрипт и стенд
сохранены в `.superpowers/sdd/2026-10-28-mihomo-import-stage8/`.
