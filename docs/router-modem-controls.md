# Диагностика LTE-модемов

Раздел `Диагностика роутера → LTE / модемы` показывает состояние, которое
Keenetic отдаёт через RCI, и позволяет проверить управляющий транспорт
конкретной карточки. Панель не перезапускает модемы: USB-устройствами и их
повторной инициализацией управляет KeeneticOS.

## Что доступно

- `Обновить` читает LTE inventory через RCI и обновляет состояние модемов,
  сети, сигнала и интерфейсов.
- `Проверить управление` выполняет только read-only проверку для указанного
  RCI-идентификатора. Он не меняет режим модема, APN, диапазоны, PIN или
  маршрутизацию.
- В блоке постоянно показано пояснение: `Перезапуск из панели отключён:
  модемами управляет Keenetic.` Для ручного восстановления используйте
  штатный веб-интерфейс KeeneticOS.

Проверка не принимает путь устройства, IMEI или команду из браузера. Она
получает текущий LTE inventory через RCI и выбирает только указанный
`modem_id`.

## Как определяется транспорт

1. Для character devices `/dev/cdc-wdm*` backend вызывает read-only
   `qmicli --dms-get-ids`.
2. QMI относится к карточке только при совпадении IMEI с RCI; при совпадении
   он имеет приоритет.
3. Если QMI не подтвердился, проверяются `/dev/ttyUSB*` командами `AT` и
   `AT+CGSN` на скорости 115200. TTY принимается только при ответе `OK` и
   совпадении IMEI.

Порядок устройств и фиксированный `/dev/ttyUSB1` не используются как способ
выбрать модем. При отсутствии IMEI, несовпадении или недоступном устройстве
возвращается безопасный статус без транспорта. Сырые ответы QMI/TTY, IMEI и
пути устройств не попадают в API-ответ.

Общий лимит probe составляет 12 секунд, включая кандидаты QMI и TTY. Это
ограничивает ожидание на устаревших или неотвечающих device files.

## `qmi-utils`

Для QMI-проверки на роутере должен быть установлен `qmi-utils` (`qmicli`).
Панель не устанавливает пакет автоматически. Если QMI недоступен, интерфейс
показывает команду:

```sh
opkg update && opkg install qmi-utils
```

Отсутствие `qmi-utils` отключает только QMI-проверку: при совпавшем по IMEI
TTY может быть показан как доступный fallback.

## API

- `GET /api/system/router/lte` — RCI inventory LTE-модемов;
- `POST /api/system/router/lte/<modem_id>/probe` — read-only capability probe.

Маршрутов reset, фоновых операций и повторного опроса операции больше нет.
Это намеренное ограничение безопасности: командный reset через QMI вызывает
power cycle устройства и на управляемых Keenetic USB-модемах может нарушить
переинициализацию не только выбранного, но и соседнего WAN-интерфейса.

## Границы функции

Код не устанавливает автоматически `qmi-utils`, `libqmi`, `uhttpd_kn` и не
создаёт отдельный HTTP-сервис. Он не посылает `AT+RESET` и не выполняет QMI
команды смены режима. Скрипты низкоуровневого сброса не являются частью
панели и не используются backend-ом.
