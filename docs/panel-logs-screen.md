# DevTools → «Логи панели»

Переделана 23 октября 2026 года по макетам, вариант B: стиль экрана «Логи Xray» ([xray-logs-screen.md](xray-logs-screen.md)). Документ описывает устройство вкладки и то, что нельзя сломать при правках.

## Что видит пользователь

- **Шапка в одну строку:** название и состояние («Снимок» / «Онлайн» / «Пауза»), файлы сегментом с размерами, уровень «Все / Предупр. / Ошибки» с числами, группа **Онлайн ⇄ Пауза / Стоп**, поиск (клавиша `/`, Esc очищает), меню «⋯» и полный экран (Esc выходит).
  - В сегменте только файлы с содержимым. Пустые и отсутствующие (обычно ws, stdout, stderr) лежат в меню, в разделе «Пустые логи». access.log панели не показывается совсем: его содержимое видно на экране логов Xray.
  - «Онлайн» по умолчанию выключен, выбор запоминается в браузере (ключи `xkeen.devtools.logs.*` прежние). Пауза замораживает таблицу, строки копятся. «Продолжить +N» показывает накопившееся.
- **Меню «⋯»:** «Вид» (следить за концом, сворачивать повторы, строк в окне, опрос без WebSocket) и «Данные» (копировать видимое, скачать файл, загрузить ещё, обновить снимок). Очистка файла стоит отдельно, красным, и спрашивает подтверждение.
- **Чипы источников** (если источников больше одного): нажатый чип скрывает источник и зачёркивается, «Показать все» возвращает. Из раскрытой строки есть «Только «…»» и «Скрыть «…»».
- **Таблица:** время, уровень, источник, событие, а бледным текстом в той же строке первые три параметра `ключ=значение`. Справа — счётчик повторов или длительность. Смена дня — строка-разделитель («Сегодня», «Вчера», дата). Клик или Enter по строке раскрывает подробности: все параметры, трассировку или вывод, исходные строки, кнопки.
- **Повторы подряд сворачиваются:** одинаковые записи (уровень и текст после времени) — одна строка `×N с <время первой>`. Время в строке — последнего повтора. Отключается в меню.
- **Телефон (уже 640 px):** строка в две линии — время и источник сверху, событие снизу. Высота строки 48 px вместо 32.

## Как читаются файлы

| Файл | Как показывается |
|---|---|
| core.log, ws.log | `ГГГГ-ММ-ДД ЧЧ:ММ:СС,мс [УРОВЕНЬ] сообщение \| ключ=значение, …` (`core/logging.py`, `core_log`). Строки без времени (трассировка) относятся к записи выше. Значение может содержать запятые (`cleared={'xray_logs': 1, …}`): новый ключ начинается только с `, имя=`. Источник — по началу сообщения (`fileops.`/`fs.`/`remotefs.` → «Файлы», `memory guard` → «Память», `happ` → «Утилита ссылок» и т. д., таблица `CORE_SOURCES`). Если сообщение начинается с имени источника и двоеточия, оно убирается. |
| update.log | Журнал старого обновления панели: одна запись на запуск от `=== … updater start ===` до `… done ===`. Шаги `[*]`/`[!]` — с временем, вывод установщика свёрнут. Запуск без `done` — ошибка (с текстом последнего `[!]`), последний незаконченный — «Обновление идёт». Сейчас этот файл никто не пишет (старое обновление снесено 11.10.2026), на роутерах он остался от прошлых версий. |
| restart.log | Журнал операций Xkeen: запись на строку `source=… result=…`, вывод xkeen и ядра перед ней — в подробностях. Подписи источников общие с журналом на экранах панели: `static/js/features/restart_log_sources.js`. Вывод без итога в конце — запись «вывод без итога». |
| stdout, stderr, xkeen-ui | Свободный текст: время из `[ISO]`, `ГГГГ/ММ/ДД`, строки доступа Werkzeug (источник HTTP, уровень по коду ответа) или формата core.log; метка `[install]` становится источником; уровень — по словам error/failed/warn и т. п.; строки с отступом — к записи выше. |

## Устройство

| Файл | Роль |
|---|---|
| `static/js/features/panel_log_parser.js` | Строки файла → записи. Чистые функции, тесты в `tests/test_panel_log_parser_js.py` (в `node`, строки с 45.1). |
| `static/js/features/panel_log_view.js` | Таблица: фильтры, счётчики, виртуальные строки в shadow DOM, раскрытие, чипы. |
| `static/js/features/devtools/logs.js` | Контроллер вкладки: список файлов, хвост с курсором, WebSocket `/ws/devtools-logs` и опрос, онлайн/пауза, меню, настройки. API для `devtools.js` прежнее. |
| `static/devtools-operator.css`, раздел 9 | Шапка, чипы, рамка таблицы, подвал, полный экран. Классы шапки — те же `.xk-xlog-*`, что у логов Xray: `panel-operator.css` на DevTools не грузится, поэтому правила повторены под `#dt-tab-logs`. |

Окно пересобирается целиком при каждом обновлении: файлы маленькие и редкие, а группировка (запуски, вывод журнала) зависит от строк, пришедших позже. Строки таблицы привязаны к id записи (первая строка и номер её повтора), поэтому раскрытая строка остаётся раскрытой, а неизменившиеся строки не перерисовываются. Разбор 610 строк core.log с 45.1 — около 5 мс.

Проверки: `tests/test_panel_log_parser_js.py`, `e2e/devtools_panel_logs.spec.mjs` (сегмент, свёртка, чипы, уровни, update.log, онлайн с паузой), `e2e/devtools_operator_theme.spec.mjs`.
