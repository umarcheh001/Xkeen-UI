# Mihomo node import — этап 7: пакетная подготовка и ограничение отображения

Дата: 28 октября 2026 года. Продолжение этапа 6 по выбранному владельцем варианту А.

## Изменения

- `POST /api/mihomo/patch/apply_batch` принимает уже распознанные узлы,
  исходный текст и группы; возвращает полный текст либо ошибку.
  Скачивание источника и выпуск Amnezia не повторяются. Одиночный
  `apply_insert` сохранён для остальных клиентов.
- Shared adapter `mihomo_config_operations.js` владеет блокировкой,
  pending registrations и job monitoring. Неиспользуемые функции
  последовательной вставки и ожидания job удалены из контроллеров.
- Список карточек ограничен 50; число скрытых показано явно. Полный список
  остаётся в импорте. Пакет свыше 512 узлов отклоняется явной ошибкой.
- Технические представления строятся при раскрытии; отображается не более
  240 строк с указанием оставшегося количества. Сохранение не обрезает конфиг.
- Пустое открытие и review не создают CM/Monaco. При закрытии редакторы
  освобождаются, ResizeObserver отключается, layout frame отменяется.
  Парсинг защищён session/revision guards; фоновый restart job не отменяется.
